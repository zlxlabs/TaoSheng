# 卡 188b 交付说明：推送设置页加「每日屏幕时间」开关

## 做了什么

推送通道编辑页里，「每日足迹」后面加了「每日屏幕时间」块，写法照足迹。

- 开关「推每日屏幕时间」写入已有字段 `sub.screenTime`；打开后可选 12/18/20/21/22/23 点，写入 `screenTimeAt`。
- 副标题按该页 `format` 状态：JSON 为「总时长和用得最多的 App；自定义接口另附完整时间线」，其他格式为「总时长和用得最多的 App（只有 JSON 格式会附带完整时间线）」。`format` 从 `ChannelSheet` 传入 `SubscriptionEditor`，不走 `caps`。
- 总开关门控：`AppGraph.isScreenTimeReady && screenTimeSettings.enabled`（`collectAsStateWithLifecycle`，写法同本页备份状态）。总开关关且本通道未订时，开关不响应点击、透明度 0.4，并提示「屏幕时间未开启，先在“设置 → 屏幕时间”里打开。」以前开过的通道仍可关掉。
- 打开后 caption：「App 使用记录会推到这个通道，注意保管。」
- `ToggleRow` 增加可选 `enabled`（默认 true），仅本块使用；未改推送逻辑、订阅字段和「设置 → 屏幕时间」页。

## 怎么验证的

- `./gradlew -PskipSigningSecrets=true :app:assembleDebug -q` → 见提交后验证记录
- 本卡是界面卡，不写单元测试

## 真机验收步骤

目标机：小米 14 Pro（澎湃 OS）。

1. 设置 → 屏幕时间：总开关保持关闭。打开设置 → 推送通道，点开任一通道：应看到「每日屏幕时间」块，开关发灰点不动，下方提示先去设置里打开。
2. 打开总开关后再进同一通道：开关可打开；打开后出现「每天几点推」（12、18、20、21、22、23），选一个保存，再进去应仍是该时刻。
3. 自定义接口通道把格式切到 JSON：副标题含「自定义接口另附完整时间线」。切到 Markdown/纯文本：副标题含「只有 JSON 格式会附带完整时间线」。
4. 通道已打开屏幕时间推送时，关掉总开关，再进该通道：开关仍可关掉（不能再打开），时刻选择仍在直到关掉。
