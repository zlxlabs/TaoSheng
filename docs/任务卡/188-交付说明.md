# 卡 188 交付说明：屏幕时间设置页（总开关与授权引导）

## 做了什么

设置里加了「屏幕时间」一页，负责人可以打开或关闭总开关；打开且没有「使用情况访问」时引导去系统设置。顺带改了整理情境开关的说明。

1. **入口**（`SettingsScreen.kt` / `SettingsHome.kt` / `SettingsIcons.kt`）
   - `SettingsPage` 加 `ScreenTime("屏幕时间")`。
   - 设置首页「记录」组、足迹下一行：标题「屏幕时间」，开着副标题「记录每天用了哪些 App」、关着「未开启」；只在 `AppGraph.isScreenTimeReady` 时显示。
   - 新增时钟 glyph 和暖色 tint（仿足迹行）。
2. **路由**（`MainActivity.kt`）：`SettingsPage.ScreenTime -> ScreenTimePage(...)`，与足迹同一写法。
3. **页面**（新建 `app/src/main/java/app/resound/ui/screentime/ScreenTimePage.kt`）
   - 总开关「记录屏幕时间」读 `screenTimeSettings.enabled`，切换调 `setEnabled(on)`；偏好写入失败（`IllegalStateException`）时页内提示「保存失败，请重试」，开关维持原值。
   - 说明文字按卡面逐字。
   - 总开关打开时显示「使用情况访问：已开启 / 未开启」；未开启时有「去开启」，跳转复用 `MicHolderGuess.openSettings()` / `permitted()`，不复制判断逻辑。从系统设置返回（`ON_RESUME`）刷新授权状态。
   - 从关切到开且未授权时弹一次说明：「需要“使用情况访问”权限才能读取 App 使用记录」，按钮「去开启」/「稍后」。升级后不主动弹。
4. **情境开关说明**（`DigestTimingCard.kt`）：按卡面逐字改成含「开启屏幕时间后还会附上当时在用的 App」。

## 真机验收步骤

目标机：小米 14 Pro（澎湃 OS）。升级安装后：

1. 打开回响 → 设置首页「记录」组，足迹下面应有「屏幕时间」，副标题「未开启」（总开关默认关）。
2. 点进去：总开关关着，没有授权状态行，也不弹对话框。
3. 打开「记录屏幕时间」：开关应保持打开；若尚未给「使用情况访问」，弹出说明「需要“使用情况访问”权限才能读取 App 使用记录」，按钮「去开启」/「稍后」。
4. 点「去开启」进入系统设置，打开本 App 的使用情况访问，返回回响：授权状态行应变成「使用情况访问：已开启」，「去开启」按钮消失。
5. 点「稍后」则对话框关掉，授权行仍是「未开启」，可再点行内「去开启」。
6. 关掉总开关：授权行消失；设置首页副标题变回「未开启」。再打开且仍未授权时才会再弹一次，升级后进页不主动弹。
7. 整理设置里「整理时参考地点和环境音」的说明应含「开启屏幕时间后还会附上当时在用的 App」。

保存失败提示无法在真机稳定复现（偏好写入几乎总会成功），代码路径是 `setEnabled` 抛 `IllegalStateException` 时页内出「保存失败，请重试」。
