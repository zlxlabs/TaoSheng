# 187 交付说明：屏幕时间推送主题与订阅文档一节

## 做了什么

- 新增推送主题 `PushTopic.ScreenTime`（每日屏幕时间）。`PushSubscription` 增加 `screenTime`（默认关）和 `screenTimeAt`（默认 22:00）；旧 JSON 缺字段仍可读。
- `:shared` 新建 `ScreenTimeReports.build`：总开关关（`enabled = false`）返回 null；时长按包名汇总后四舍五入到整分钟，`totalMinutes` 取全部段总毫秒四舍五入（不是各 App 分钟之和）；`apps` 按分钟降序、同分钟按包名升序完整列出。
- Webhook JSON 在 `footprint` 之后带 `screenTime` 对象（字段顺序：`schemaVersion`、`date`、`coverageUntil`、`totalMinutes`、`apps`、`timeline`、`devicePlayback`、`gaps`）。Markdown/文本格式只发 title + body。`X-Resound-Type: screen_time`，`X-Resound-Date` 取 `screenTime.date`。`devicePlayback` 本卡恒为空数组。
- 新建 `ScreenTimePushWork`（Worker / Scheduler / `attachScreenTime`）。`AndroidPushChannels` 增加 `screenTimeMessage`、`dispatchScreenTime`、`nextScreenTimeAt`、`pushScreenTimeNow`；已发标记键 `screen-time-sent-<channelId>`。总开关关（reader 为 null 或报告为 null）不发、不写已发标记。「立即推送一次」同时接上屏幕时间。
- 订阅文档：主题打开且报告非 null 时，当天文件末尾追加 `<!-- resound:screen-time -->` + `## 屏幕时间` 一节；关闭时不追加并去掉已有节。

查询区间：当天 00:00 到推送时刻。无授权时照常发出，列表为空、`gaps` 带 `usage_access_missing`。

## 怎么验证的

- `python3 tools/check_shared.py`：通过。
- `./gradlew -PskipSigningSecrets=true :shared:check -q`：exit 0。
- `./gradlew -PskipSigningSecrets=true :shared:jvmTest --tests 'app.resound.screentime.*' --tests 'app.resound.push.*'`：exit 0。
- `./gradlew -PskipSigningSecrets=true :app:testDebugUnitTest --tests 'app.resound.push.*'`：exit 0。
- Linux 无 Xcode，`zsh tools/check_ios.sh` 跳过，**主脑需在 Mac 补跑**（改了 `:shared` 共用代码）。

## Webhook 最短接通

1. 总开关「屏幕时间」打开（待 186c 装配后才生效），并授予使用情况访问。
2. 推送设置里加一条自定义接口（Webhook），格式选 **JSON**，打开「每日屏幕时间」，时刻默认 22:00。
3. 点「现在推一次」，或等到点。请求头：`X-Resound-Type: screen_time`、`X-Resound-Date: YYYY-MM-DD`。
4. 格式不是 JSON 时只有标题和正文，没有 `screenTime` 字段。

完整样例（与单测逐字节断言同一条，`devicePlayback` 为空数组）：

```json
{"title":"今日屏幕时间 3 小时 12 分","body":"哔哩哔哩 192 分\n部分时段没有数据：等待下一次采集","topic":"ScreenTime","deepLink":null,"at":1794657600000,"screenTime":{"schemaVersion":1,"date":"2026-11-14","coverageUntil":"2026-11-14T22:00:00+08:00","totalMinutes":192,"apps":[{"package":"tv.danmaku.bili","name":"哔哩哔哩","minutes":192}],"timeline":[{"package":"tv.danmaku.bili","name":"哔哩哔哩","start":"2026-11-14T17:11:46+08:00","end":"2026-11-14T20:23:46+08:00"}],"devicePlayback":[],"gaps":[{"code":"coverage_lag","source":"screen","from":"2026-11-14T21:00:00+08:00","until":"2026-11-14T22:00:00+08:00","fix":"等待下一次采集"}]},"type":"screen_time","version":1,"app":"resound"}
```
