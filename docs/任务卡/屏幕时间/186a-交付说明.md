# 卡 186a 交付说明：屏幕时间查询仓储 ScreenTimeQueries

## 做了什么

- 新建 `shared/src/commonMain/kotlin/app/resound/screentime/ScreenTimeQueries.kt`：`ScreenTimeReader` 的唯一实现。`sessions(from, until)` 流程与卡面锁定决策一致：
  1. `until <= from` 抛 `IllegalArgumentException`（在开关判断之前）；
  2. 总开关关闭 → 直接返回 `ScreenTimeResult.DISABLED`，拉取器与 DAO 都不碰；
  3. 先 `puller.pull()`；`Failed` 时在返回值 `gaps[]` 末尾追加一条 `pull_failed`（区间取 `[coveredUntil ?: from, now())` 与 `[from, until)` 的交集，交集为空不记；**只在查询结果里带出，不写库**，避免每次查询重复落库），不阻断查询；
  4. `dao.events(from − lookback, until)` 转事件，`ScreenEventType.of` 为 null 的行丢弃；
  5. `ScreenTimeRules.sessions(..., coveredUntil = 拉取后重读的 state?.coveredUntil ?: from, ...)`；
  6. 用 `dao.names()` 拼显示名，经 `ScreenTimeText.clean` 脱敏；查不到名称用包名（同样脱敏）。
  - `gaps` 顺序固定：落库缺口（按 from 升序）→ `usage_access_missing` → `coverage_lag`（此刻−coveredUntil 超 1 小时且区间与查询相交时现算）→ `pull_failed`。六种 code 的 `fix` 文案按卡面定死；落库行遇到未知 code 直接抛错（fail fast）。
- 新建 `ScreenTimeText.kt`：回车/换行/制表符与【】｜《》各换成一个空格、去首尾空白、按 Unicode 码点截断（代理对不拆），被截断时末尾加「…」（不计入上限）。平台无关，纯 Kotlin 字符处理，无 `java.*`。
- 新建 `shared/src/jvmTest/kotlin/app/resound/screentime/ScreenTimeQueriesTest.kt`：8 个用例（必测 6 项全覆盖，其中必测 6 拆成 2 个断言函数）。
- 未改 `ScreenTimeRules.kt`、185b 的 DAO/拉取器/设置、`ScreenTimeContract.kt`；不装配（归 186c）。

## 待 186c 装配

`ResoundApp.kt` 里 185b 装配段（`screenTimeSettings` 赋值之后）改为先把事件源提成本地变量，再构造查询仓储（`permitted` 与拉取器传同一实现）：

```kotlin
val screenTimeSource = app.resound.screentime.AndroidScreenEventSource(this)
AppGraph.screenTimePuller = app.resound.screentime.ScreenTimePuller(screenTimeSettings,
    screenTimeSource, database.screenTime(),
    now = AppGraph.platform.now::now, denied = { it is SecurityException },
    diagnostic = { android.util.Log.i("screentime", it) })
AppGraph.screenTimeReader = app.resound.screentime.ScreenTimeQueries(
    database.screenTime(), AppGraph.screenTimePuller, screenTimeSettings,
    permitted = screenTimeSource::permitted,
    excluded = setOf(
        "com.miui.home",   // 小米/澎湃 OS 桌面（目标机）
        "com.android.launcher3", // 通用 AOSP 桌面
        "com.google.android.apps.nexuslauncher", // Pixel 桌面
    ),
    now = AppGraph.platform.now::now,
)
```

- `config` 用默认 `ScreenTimeConfig()`，不用传。
- `AppGraph.screenTimeReader` 保持可空：开关关闭或未装配时消费方按 `DISABLED` 处理（`AppGraph.kt` 注释既有约定）。
- `disabled` 缺口由 185b 已装的 `onReenabled` 回调补写，查询侧只负责按区间读出，186c 无需再做。

## 遗留问题

- `ScreenTimeRules` 已知缺陷（「A、B(2秒)、A」合并重叠场景，186c 修）不在本卡范围；`ScreenTimeQueries` 对此无感知，规则修好后查询结果自动修正。
