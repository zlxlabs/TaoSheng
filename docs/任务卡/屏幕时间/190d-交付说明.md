# 卡 190d 交付说明：设备播放记录的界面（通知使用权引导、开关说明文字）

## 做了什么

1. **设置 → 屏幕时间页（`ScreenTimePage.kt`）**
   - 总开关打开时，在「使用情况访问」卡片下面新增「设备播放记录（可选）」卡片：显示通知使用权是否开启；未开启时右侧有「去开启」。
   - 通知使用权状态 `listenerOn` 用 `NotificationManagerCompat.getEnabledListenerPackages` 判定，初值与返回本页（`ON_RESUME`）时刷新，写法与现有「使用情况访问」一致。
   - 「去开启」跳转：API 30 及以上进该服务的通知使用权详情页（类名字符串写死 `app.resound.screentime.PlaybackListenerService`，本卡不引用 190b 的服务类）；更低版本进系统通知使用权总列表。不在打开总开关时自动弹引导。
2. **设置 → 整理时机（`DigestTimingCard.kt`）**
   - 「整理时参考地点和环境音」下面的说明补上外放来源：开启屏幕时间后附上当时在用的 App 和外放来源（开启通知使用权时带节目标题）。其余文字和样式未改。

## 怎么验证的

- Accept-Check：`./gradlew -PskipSigningSecrets=true :app:assembleDebug -q`（exit 0）。
- 不写单元测试（卡面：界面由真机验收）。

## 真机验收步骤

1. 设置 → 屏幕时间：打开总开关后，「使用情况访问」下面应出现「设备播放记录（可选）」卡片；未授权时显示「未开启」和「去开启」。
2. 点「去开启」应进入系统通知使用权页（API 30+ 应尽量落到本应用该项；更低版本为总列表）。
3. 授权后返回本页，卡片应显示「已开启」，「去开启」消失。
4. 设置 → 整理时机：「整理时参考地点和环境音」说明应含「外放来源（开启通知使用权时带节目标题）」。

## 遗留问题

- 今日页卡片和详情页按方案 J46 不做（可选，降为最后）。
- 监听服务本身由卡 190b 落地；本卡只写死类名字符串做跳转，190b 未合入时系统设置页可能找不到对应服务项。
