# 设备播放记录与外放归属

上游可独立合并的「播放检测 + 外放归属」：不开通知使用权时，外放片段整理会标「手机在外放」；用户打开「记录播放标题」并授权后，标注可带上 App 和节目标题。屏幕时间采集、每日推送、今日卡片、问问 `apps_during` 不在本范围。

## 功能

- **记录播放标题**（默认关）：独立于屏幕时间。关闭时播放事件零写入；打开后若系统里已有正在播放的媒体会话，立即补记为开始。
- **通知使用权**：打开标题开关但没有通知使用权时，原话设置页显示「去开启」。不读通知内容。系统撤销授权时保留已有历史，并记一段缺口。
- **外放标注**：麦克风片段扬声器外放满 3 秒时：
  - 能匹配到播放记录 → `外放：可能是 某App《标题》` 或 `外放：可能是 某App`
  - 否则一律 `外放：手机在外放`
  - 不再出现「来源未知」「前台 App 兜底」或「在用」情境行。
- **整段外放暂不整理**：系统判成外放、用户仍要转写的片段会转写，但先不进整理；原话页可放行。

## 设置位置

「原话与转写」页，和外放声音时不转写放在一起。开关和开启时刻随设置备份。

## 数据库 34→37

沿用已定的三步迁移和五张表结构，本范围不改 schema。屏幕时间四张表在本版本中是空表；播放断连缺口仍写在 `screen_coverage_gaps`（source=`playback`）。隐私删除仍会清这五张表。

当前 `CaptureDatabase.VERSION = 37`。升到最新版本的测试断言用 `CaptureDatabase.VERSION`。

## 怎么验证

```

./gradlew -PskipSigningSecrets=true :app:testDebugUnitTest \
  --tests 'app.resound.screentime.*' --tests 'app.resound.data.*' \
  --tests 'app.resound.transcribe.*' --tests 'app.resound.digest.*' \
  --tests 'app.resound.privacy.*' --tests 'app.resound.backup.*' \
  --tests 'app.resound.push.*'

```

覆盖：播放记录门控与打开时补记、外放标注新文案、播放只读查询、34→37 schema、设置备份往返、按时间遗忘清播放记录。

本机没有 Xcode，未跑 iOS 编译检查。

## 真机注意事项

- 目标机：小米 14 Pro（澎湃 OS）。通知使用权是系统特殊权限，应用里只能跳转，不能代开。
- 关闭「记录播放标题」时不应写入播放行；打开时若正在外放播客，应立即出现一条开始记录。
- 不开通知使用权时，外放片段整理标注为「手机在外放」。
- 需要看的界面：设置 → 原话与转写（记录播放标题、去开启通知使用权）；原话页外放暂不整理与放行。
